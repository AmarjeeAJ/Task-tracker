MERN Candidate Assignment: Build a Mini Task Tracker

Build a task tracker using Postgres SQL, React.rs/React.ts and Node.js.

Required functionality

Create a task with a required title of up to 100 characters, optional description, status, priority, and created timestamp.
Support statuses of To Do, In Progress, and Done, and priorities of Low, Medium, and High.
Display tasks in a list.
Update a task’s status.
Delete a task after confirmation.
Filter tasks by status.
Persist data in MongoDB.
Validate inputs on the server and display useful errors in the interface.
Include loading, empty, and error states.
Add two meaningful tests: invalid task creation and successful status update.
Expected APIs

POST /tasks — Create a task.
GET /tasks — List tasks with optional status filtering.
PATCH /tasks/:id — Update task status.
DELETE /tasks/:id — Delete a task.
Authentication and cloud deployment are outside the assignment scope. Include a short explanation of how authentication and access restrictions would be added for production.

Source code through a private repository or ZIP file.
README with setup steps, test commands, assumptions, and limitations.
Environment-variable example file without credentials.
Brief explanation of technical decisions and improvements to make with more time.
